## 1. Token

全部在 `styles/tokens.css`，多套浅色/深色调色板挂在 `html[data-theme]` 上，明暗标记在 `html[data-scheme]`。组件里取值的写法只有一种：`var(--*)`。

三条约定：

- 对比度门槛：正文与小字 ≥4.5:1，标题与主正文 ≥7:1。改色板后跑一遍计算，结论写进 PR。
- 暗色的层级用 `--c-surface` 与 `--c-surface-1` 的亮度差 + 1px `--c-hairline` 表达；投影留给浅色模式。
- 表面只有三档 + scrim，区块分隔优先用留白（§1.3）。

### 1.2 字体与字阶

```css
--font-body: system-ui, -apple-system, "Segoe UI Variable Text", "Segoe UI",
             "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC",
             "Microsoft YaHei UI", "Microsoft YaHei", sans-serif;
--font-mono: "SF Mono", "Cascadia Mono", "JetBrains Mono", Consolas,
             "Noto Sans Mono CJK SC", monospace;
```

**拉丁字体排在 CJK 之前**，`Microsoft YaHei` 保持在列表末段。

字阶 5 档，组件的 `font-size` 一律从中取：

| token | size / line-height | 用在哪 |
|---|---|---|
| `--t-display` | 22px / 30px，500 | 页面大标题 |
| `--t-title` | 17px / 26px，500 | 卡片首行、详情首屏、对话框标题 |
| `--t-body` | 15.5px / **1.85** | 日记正文（Vditor 也用它）、列表预览 |
| `--t-small` | 13px / 1.5 | 元信息、chip、按钮文字 |
| `--t-caption` | 11.5px / 1.35，500 | 周条星期、月历日号下的打点数、n/N 计数 |

- 正文行长上限 `--measure: 34em`（约 34 个汉字），宽容器里居中，左右留白承担呼吸感。
- 字重取 400 / 500 / 600（600 只给数字与今日）。
- 中文段落左对齐；`letter-spacing` 取默认值。
- PRD §7 的"首行缩进"开关实现为 `text-indent: 2em`，作用范围是 `p`；标题、列表项、代码块齐头。

### 1.3 间距、圆角、层级

- 间距标度取 4 的倍数：`--s-1…--s-8 = 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`。
- 固定节奏：卡片内边距 16（窄）/ 20（宽）；列表项纵向 12；区块之间 24；同一行 chip 之间 8；图标与文字之间 6（16px 图标专用，属 §1.4 例外清单之外的唯一半步）。
- 圆角：`--r-sm 6`（chip、小按钮）/ `--r-md 10`（卡片、输入框、缩略图）/ `--r-lg 14`（浮层、对话框）/ `--r-pill 999`（今日环、计数徽标）。同一层元素用同一档。
- 投影两档，只在浅色模式下生效：
  `--e-1: 0 1px 2px rgba(17,19,18,.04), 0 1px 3px rgba(17,19,18,.06)`（轻微）
  `--e-2: 0 10px 30px rgba(17,19,18,.16)`（月历浮层、对话框、浮动按钮）
- 触控目标最小 **44×44**。视觉尺寸可以更小（月历格子 36×36，用 `::before` 把热区撑到 44）。

### 1.4 允许写死的东西（封闭清单）

1px 发丝线、`env(safe-area-inset-*)`（仅作 `--safe-top` / `--safe-right` / `--safe-bottom` / `--safe-left` 的回退默认值）、Vditor 内部尺寸、SVG `stroke-width`、`1em`/`2em` 这类与字号联动的相对值。这份清单之外的字面值由 `check-style.mjs` 拦截（§7）。

## 2. 骨架尺寸

**窄屏（<600）** 自上而下：安全区 → 顶栏 52 → 周条 76 → 今天卡片（仅日记今天）→ 当日列表 → 底部导航 56 + 安全区。
**宽屏（≥960，或高度 <600 且宽度 ≥720）** 全局侧轨 184 + 内容区：`184px | minmax(0, 1fr)`。`/today` 在宽屏里先分两栏 `300px | minmax(0, 1fr)`（迷你月历｜列表），详情仍是整页路由；屏幕到 **≥1200** 时才变成三栏 `240px | minmax(300px, 1fr) | minmax(420px, 1fr)`，详情嵌进第三列。600–960 之间（高度 ≥600）与窄屏同一套组件树，只换间距。<br>宽度之外也看高度：横屏手机的 CSS 宽度约 780–930，但高度只有 360–430，竖排的周条 + 卡片 + 底部导航会挤掉大半内容，因此**高度 <600 且宽度 ≥720 也进宽屏档**（侧轨 + 迷你月历）。720 是下限——更窄的视口减掉 184 侧轨与 300 日历后列表已不可用，仍留在窄屏。

- 文档早先写的"≥960 即三栏"在 184px 侧轨下放不下（960 − 184 = 776 < 240 + 300 + 420），因此三栏门槛后移到 1200，属有意偏差；两栏阶段日历给 300，三栏阶段让到 240。
- 内容区默认 `max-width: 1040px` 居中；只有 `/today` 且处于三栏时放宽到 `1440px`，让第三列有足够行长。
- 三栏时点击卡片不是路由跳转，而是把条目 id 写进 `?e=`（选中日记日仍是 `?d=`）：刷新与前进后退都能还原"选中哪天 + 打开哪条"。直接访问 `/j/:id`（搜索、深链）不受影响。
- 第三列与列表之间 1px `--c-hairline`，两栏各自独立滚动；没有选中条目时显示居中占位（铅笔图标 + "选择一条记录"）。换条目时详情栏 `scrollTop` 归零。
- 软键盘由 Android IME insets 驱动（DESIGN §9 第 8 条）：`--ime` 等于键盘高度，`.app` 高度按 `100dvh - var(--ime)` 收缩；键盘打开时底部导航与浮动按钮隐藏，焦点所在的输入框/编辑器把光标滚入可视区。视口高度始终取 `100dvh`，不监听 `visualViewport`。
- 输入类浮层（确认、口令、备份、锁屏）在 `--ime` 内居中避让；附件查看器不响应键盘，只避让四边安全区。
- Android 返回键与手势按叠层顺序消费：浮层 → 路由历史 → 退出应用（DESIGN §5）；锁定状态下不动路由。
- 横屏/挖孔：左右安全区与上下同等处理；系统栏图标明暗跟随 App 主题，不跟随系统亮暗。

## 3. 九个高风险界面

### 3.1 WeekStrip（首页常驻周条）

7 格等宽（`(100% - 2×12) / 7`），每格三行：`--t-caption` 星期缩写 → `--t-title` 日号 → 打点行（高 6）。

- 打点编码：1 条内容 = 1 个 4px 圆点（`--c-primary`）；2–3 条 = 3 个点；>3 条 = 2 个点 + 一个数字。点的大小恒定。
- 状态叠加靠形状，颜色只是加强：今日 = 日号外 `1.5px --c-accent` 环；选中 = `--c-primary` 实心 pill 底 + `--c-on-primary` 字；今日且选中 = 实心 pill + 环。这是本项目唯一的无障碍硬要求。"今日"按日记今天判定（PRD §2.8）：凌晨未过分界点时，高亮的是前一天。
- 横滑换周，跟手；松手按位移过半吸附，180ms。所有日期都可选，历史与未来只读（PRD §2.2、§2.8）。
- 周网格切换用同方向的 180ms 淡入 + 16px 横向位移；离场层不接收指针事件（§5.1）。
- 左右两端各留 12px 渐变遮罩暗示可滑。周跨月时不额外标注月份。

### 3.2 MiniCalendar / MonthSheet

同一份 `MiniCalendar.vue`，桌面嵌左栏（格子 32），移动在浮层里放大（格子 44）。日历自己实现（[DESIGN §8](./DESIGN.md)）。

- 网格固定 7×6，切月时高度恒定。
- 今日环按日记今天判定（PRD §2.8）：凌晨未过分界点时，高亮的是前一天。
- 邻月补白：字色 30% 透明度、无打点、热区只用于显示。切月手段是顶部 ←/→ 与横滑。
- 周起始日读设置（PRD §2.7），表头随之整体平移。表头与格子同宽，容器宽度取 `fr` 或百分比。
- 键盘（桌面）：↑↓←→ 走天，PgUp/PgDn 走周，Home/End 走周首周末，Enter 选中，Esc 关闭浮层并把焦点还给触发它的按钮。
- 翻月：7×6 网格叠放在同一格，离场层绝对定位且 `pointer-events: none`；新月份 240ms 淡入、16px 横向位移，方向按月份先后（§5.1）。
- 浮层：从顶部下拉展开，`--r-lg` + `--e-2`，240ms、位移 24px、配合淡入，背后 `--c-scrim`。

### 3.3 TodayCard

只在选中的日期就是日记今天时挂载（PRD §2.8）；选中其他日期时整块撤走，列表直接顶到顶栏下方。

- 空态：单行输入 + 底部 32px 操作区；`--c-surface-1` 底 + 1px `--c-hairline` + `--r-md`，placeholder "此刻在想什么…"。聚焦时描边换 `--c-primary`。
- 有内容：1→6 行自动增高（行高 26），超过 6 行内部滚动；右下角出现 32px 的"保存"按钮；左下角 `--t-caption`：空内容显示"失焦自动保存"，有内容显示字数。
- 保存触发两个：失焦 / "保存"按钮。**不走去抖自动保存**——它是一次性提交的快速入口，不是详情编辑器。
- 保存态用文字表达：`saving` = "保存中…"；`saved` = 勾 + "已保存"，停 2s 后回到字数；`error` = `--c-danger` 的"未保存 · 重试"，正文保留、可再次提交。
- 空白内容不提交：trim 后为空时，失焦与按钮都什么也不做，卡片保持原样，也不产生空条目。
- 提交成功后卡片清空、高度复位，列表刷新并停在今天；不写"今天已存 n 条"这类常驻统计。
- 附件入口在底部左侧：32px 图片按钮打开系统文件选择器；粘贴与拖入文件同样生效（细则见 §3.9）。导入中状态行显示"正在插入媒体…"，拖入时按类型显示"正在插入图片/视频/音频…"（混合为"正在插入音频或视频…"），保存不可用。
- 待发附件以 64×64 方块排在输入框下方；图片显示缩略图，音视频只显示 kind 文字；右上角 20px 删除按钮（scrim 圆底 + 白色 ×）。只有附件、没有文字时也允许保存，附件 markdown 追加在正文之后。

### 3.4 JournalCard

两种密度共用一套元素：**叠放态**（首页当日，`--c-surface-1` 卡）与 **结果态**（搜索/发现，靠 hairline 分隔）。

- 布局：首行 `--t-title` 两行截断 → 预览 `--t-body` 两行截断（`preview` 字段，[DESIGN §3](./DESIGN.md) 的列表摘要）→ 底行 meta。右侧缩略图 56×56、`--r-md`、`object-fit: cover`，由 `assetUrl.thumbUrl` 指向 `.thumbs/{stem}.webp`（内置 asset 协议，DESIGN §3.1）。
- meta 行只渲染有值的字段：时间（`--t-caption`）、mood 图标 16px、weather 图标 16px、图片/音频/视频数量角标（各自 `v-if` 计数 > 0，图标 + 数字）、置顶图钉。全空时整行撤走，12px 还给内容（PRD §2.3）。宽度不够时 meta 换行，不撑宽卡片（首页列表不出现横向滚动条）。
- 时间默认按日记日显示记录时间；修仙模式下分界点之前的凌晨时刻显示为 24+，如 01:00 → 25:00。设置「显示最后编辑时间」开关打开后改显示最后编辑时间，同样按修仙模式偏移。开关只有两个状态，关闭即记录时间；回收站列表同样按这个开关显示，不做特例。两者都只改显示——排序、日记日归属与分页游标始终用 `recorded_at`（记录时间），切换不会重排列表。
- 分隔方式二选一：叠放态用 `--e-1` + 纯白底；结果态用 hairline + 页面底。描边与阴影同一张卡只出现一种。
- 封面缺席时文字区铺满整行。
- 图片加载失败或已被清理：缩略图位置显示 `--c-surface-2` + 一个 20px 图标，替代浏览器默认的裂图标记。

### 3.5 DetailView：读与写一套 UI

触发方式按 PRD §2.3 定：

- **当前日记日**：从列表或主操作进入，直接是编辑态（窄屏与宽屏一致），宽屏顶栏不出现铅笔。
- **带查询词进入**：先只读并定位到第一处命中；窄屏右下角 FAB、宽屏顶栏铅笔、双击正文都可进编辑。
- **历史与未来日期**：强制只读。元信息行追加"· 仅预览"，不出现编辑铅笔 / FAB，双击无效，离开不保存；正文下方固定一句"过去的记录只能预览，不能再编辑。"。置顶与删除留在顶栏，不属于正文编辑。
- **空白草稿不落库**：新建页未输入任何内容就离开时，不创建条目；正文被清空只提示，不触发删除（PRD §2.3）。
- 切换动画：容器 `opacity` 120ms 淡出 → 卸载当前渲染器、挂载另一个 → 120ms 淡入，同时按第一行可见文字的 `getBoundingClientRect` 还原滚动位置。同一时刻容器里只有一份渲染结果（Vditor 实例配额见 DESIGN §5）。
- 只读态字号 = `--t-body` + `--measure`；标题层级由 §4 的覆盖压到 `--t-title` / `--t-body` 两档。
- **三栏内嵌**：`DetailView` 接一个可选的 `entry-id` prop，有值即处于内嵌态，不读路由参数。选中卡片的描边换 `--c-primary`；顶栏左键变成 ✕，点击先冲刷保存再 emit `close`（列表侧从 `?e=` 移除该 id），不产生路由历史。内嵌态沿用同一套读写判定：日记今天直接编辑，历史日期强制只读。
- 只读预览里点击图片打开 §3.10 的 AssetViewer；带查询词进入时，预览渲染完成后把命中文字包进 `<mark class="dd-hit">`（背景 `--c-hit`，上限 200 处），并把第一处滚到视口中央。双击进入编辑只在非只读时生效。
- **元信息行（MetaChips）**：正文上方，顺序为心情 chip → 天气 chip → 标签 chip → `+`。心情与天气各自打开同一套图标面板：固定 17 项，当前项右下角 ✓，首格是"不记录心情 / 不记录天气"的清除项；面板一次只开一个，点外部或 Esc 关闭。编辑态显示为可点 chip（已选中时用 `--c-primary`），只读态显示为静态 chip 且不打开面板。天气只记录、不参与筛选（PRD §2.6），发现页不出现天气筛选项。地点不单开字段，直接作为一个标签写。新建页的元信息行同样可编辑：心情/天气/标签先留在内存，第一次保存正文时随条目写入；正文仍为空就离开，整份草稿（含元信息）不落库。标签插入面板只列至少被一条存活日记引用的标签，零引用标签不展示（键入同名会直接复用）。

### 3.6 StateBlock（空 / 加载 / 错误）

一个组件三种形态，全 App 只此一份。

- **加载**：首屏列表 = 3 张骨架卡（`--c-surface-2` 块，shimmer 1.2s）；分页追加 = 底部一条 2px `--c-primary-soft` 进度线。打点与统计这类毫秒级查询直接渲染结果。
- **空**：图标 32（`--c-on-surface-faint`）+ 一句话；首页不给按钮，写入入口是今天卡片与主操作（§3.7）。文案按选中日与日记今天比较：`这一天没有记录` / `今天还没有记录` / `这一天还没有到来`。搜索与发现页在筛选后为空时仍给"清除筛选"出路（PRD §2.5）。
- **错误**：inline 卡片，`--c-danger` 标题 + 问题详情 + 重试按钮。详情来自 `IpcError` 的 `code / message / detail`（前端 `describeError` 拼接，保留换行、可选中复制），统一走 `hint` 渲染；错误呈现一律走这里，禁止只显示一句"出了点问题"。

### 3.7 首页写入与主操作

首页只有一个新建/定位主操作，它随选中日变化，不出现第二个新建入口或日期跳转入口。

| 选中 | 图标 | 文案 | 样式 | 行为 |
|---|---|---|---|---|
| 日记今天 | `mdiPlus` | 新建 | `--c-primary` 底 + `--c-on-primary` 字 | 进 `/j/new?edit=1`，打开即编辑 |
| 其它日期 | `mdiCrosshairsGps` | 今天 | `--c-surface-2` 底 + `--c-primary` 字 | 把选中日切回日记今天，不写库 |

- 位置：宽屏在顶栏右侧，36px pill；窄屏是右下角 FAB，46px pill + `--e-2`。两者是同一个动作的两个外壳。
- 切换：图标与文案同步切换，不做交叉淡入；按下缩放到 98%（`--m-1`）。
- 今天卡片只在选中的是日记今天时出现；其它日期没有输入区，也没有"写一条"按钮。
- 快速输入保存后：非空才提交 → 清空 → 刷新列表 → 留在今天（PRD §2.8）。
- 空态文案见 §3.6 的三句，不再带动作按钮。

### 3.8 设置行：修仙模式

挂在"我的 → 记录"组，沿用设置行：左侧标签 + `--t-caption` 副文案，右侧控件；行高 48、左右 16。

- 控件是原生 `<input type="time">`：`min 00:00`、`max 07:59`、`step 60`（按分钟），显示 `HH:mm`；`00:00` 等于关闭分界（默认）。
- 外壳与 `select` 一致：`--c-surface-2` 底、1px `--c-hairline`、`--r-sm`、`--t-small`、min-height 34；数字用 `font-variant-numeric: tabular-nums`。不在控件上单独声明 `color-scheme`，时钟图标的明暗由 `html[data-scheme]` 的 `color-scheme` 继承决定，永远跟应用主题走、不跟系统。
- 副文案固定一句："分界点之前的记录算作前一天（00:00–07:59）"。
- 改动立即生效：服务端重排历史归属并重建打点（DESIGN §2.2），不弹确认、不要求重启；回到首页即按新日记日显示。

### 3.9 附件：导入、待发条与正文

今日卡片与编辑器共用一条附件管线，差别只在附件先放在哪里。

- 入口三处：今日卡片底部 32px 图片按钮、编辑器工具栏的图片按钮、粘贴/拖入。前两者调 `media_pick_import` 打开系统选择器（桌面由 Rust 侧对话框、Android 走 SAF）；粘贴监听 `paste`（编辑器用捕获阶段，防止 Vditor 先吃掉），由 Rust 读系统剪贴板；拖放走 Tauri 原生 `onDragDropEvent`，按落点命中卡片或编辑区（DESIGN §7 第 2 条）。
- 只导入扩展名属于媒体白名单的文件，混合选择里的其他类型静默过滤；剪贴板里的位图按 `pasted.png` 入库。文件由 Rust 直接读取，字节不进 IPC。
- 返回的 `Asset` 直接可用：正文里存逻辑 URL `ddasset://{kind}/{name}`，缩略图由 `assetUrl.thumbUrl` 指向 `.thumbs/{stem}.webp`，缩略图未生成时 `img` 回落原图并在失败时显示 `--c-surface-2` 占位（§3.4 同一画法）。
- 今日卡片把返回的附件先放进输入框下方的待发条（64×64、`--r-sm`），不立即写库；保存时把 `![…](ddasset://…)` 追加在正文末尾，与文字组成同一条记录。只有附件、没有文字也算非空。
- 附件不再被正文引用就删除文件：退出编辑器（切条目前、离开详情）时先完成保存，再用「进入时正文里的引用 ∪ 本次导入 − 最终正文引用」得到待删名单，后台调用 `asset_gc`，页面切换不等结果；今日卡片的待发条点 × 或卡片卸载时同理。已写入正文的附件不受影响，删除失败只进控制台。
- 软删除进回收站保留附件文件，恢复后照常显示；彻底删除与清空回收站时，删除只被这些条目引用的附件（仍被其它条目引用的保留）。「我的 → 数据」里的「清理未使用附件」按下后扫描全部正文，删除没有被任何条目引用的附件文件。
- 导入期间禁用保存，状态行显示与编辑器一致的软提示（全是图片 → "正在插入图片…"，全是视频 → "正在插入视频…"，全是音频 → "正在插入音频…"，混合 → "正在插入音频或视频…"）；失败时状态行换成 `--c-danger` 的详情文本（超长省略、悬停看全文）。拖入文件时整卡描边换 `--c-primary`，并盖一层 `--c-primary-soft` 的"松手添加"提示，`pointer-events: none`。
- 编辑器里插入的是 IR 模式的图片节点，光标落在其后。确认文件后编辑器底部中央出现软提示 pill（`--c-surface-1` + hairline + `--e-1` + 小圆环 spinner），文案同上按类型切换；插入成功或失败后立即消失，不阻塞输入。失败时同一位置换成 `--c-danger` 的详情 pill，点击关闭；正文不变，不会留下半截引用。

### 3.10 AssetViewer（图片放大）

全屏浮层，只处理图片；音频与视频交给浏览器原生控件。

- 遮罩用接近纯黑的 `rgba(0,0,0,.82)`，图片居中、`--r-md`、最大 100% 视口，进出 180ms 淡入淡出。
- 缩放范围 0.4–6，滚轮每格 0.2；放大后可按住拖动（pointer capture），缩回 ≤1 时自动回中。双击复位。
- 右下 40px 胶囊工具栏：缩小 / 百分比 / 放大 / 复位 / 关闭，深色底 + 白字，与主题无关；底部另有一行 `--t-caption` 操作提示。
- `Esc` 关闭，点遮罩关闭。缩放与拖动自己实现，不引第三方库。

### 3.11 发现页搜索与标签筛选

顶栏自上而下：标题 → 搜索框 → `partial` 说明 → 标签 chip 行。输入查询词时标签行整体隐藏，给结果让出高度。

- 搜索框常驻顶栏，44px、`--c-surface-2` 底 + `--r-md`；有词时右侧出现清除 ✕。输入防抖 250ms，查询按 token 作废旧响应。
- 标签 chip 行：`全部` + 各标签（`#name` + 使用次数），32px、`--r-sm`；选中项 `--c-primary-soft` 底 + `--c-primary` 字。点击即查询，不做二次确认。只列至少被一条存活日记引用的标签；选中的标签失去最后一条引用后自动回到"全部"。
- 查询与标签同时生效：有词走 `search_query`，无词走 `journal_list`，两者都只带 `tagId`；单次最多 100 条，`partial` 由后端返回并显示在搜索框下方。
- 过滤后为空时，StateBlock 的标题换成"没有符合条件的记录"，右下给"清除筛选"；标签生效即算 `filtersActive`。
- 区段标题随条件变：有查询词 → "搜索结果"；选中标签 → `#tag`；都没有 → "最近"。
- 点开结果时把查询词作为 `?q=` 带到详情，详情先只读并标出第一处命中（§3.5）。

**高级搜索（暂不实现）**：心情多选（含"没有指定心情"）、起止日期、多关键词、正则表达式都属于这个范围。它不是核心或常用功能，当前不提供入口，也不预埋 UI；后端 `search_query` 的 `from` / `mood` 参数保留，将来接入时再用。

### 3.12 我的：数据动作与应用锁

**数据组排在设置页最上面**（外观之前）。先是一块统计卡：数据库、附件、日记、回收站、字数五个格子，标签在上、数字在下，数字用 `--t-title` 600 且 `tabular-nums`，数字与单位不换行；未取到数据时显示 `—`。格子之间不画分隔线。宽度 ≥560px 时五格一行等分；更窄时拆成两行——数据库与附件各占一半，其余三格各占三分之一，两行独立等分、上下不对齐，且前两格宽度不小于 100px。大小按 B / KB / MB / GB 显示。下面一行是数据目录：左侧标签 + 等宽路径，右侧两个 44px 图标按钮——文件夹图标打开目录、复制图标把路径写入剪贴板。再接五行同构动作：导出 / 导入 / 备份 / 恢复 / 清理未使用附件。整行是按钮（左主副文案、右 20px 图标），目录与备份文件（zip / ddbak）的选择走系统选择器，取消即原样返回。「清理未使用附件」是手动诊断项，副文案“扫描全部日记，删除没有正文引用的附件”，执行前走确认框，结果行显示删除个数与释放大小，没有可删的显示“没有未使用的附件”。

**备份对话框**：点“备份”先弹自绘 BackupDialog，不直接开系统保存框。创建态两个密码输入（“口令（可不填）”“确认口令”）：都留空 → 普通 zip；填了口令 → 不设长度下限，首尾不能有空格、两次一致，错误就地显示，生成 `.ddbak` 加密包。提示文案随口令实时切换：为空是“设置口令会生成加密包，留空则生成普通备份。”，不足 8 个字符是“设置口令会生成加密包，口令过短影响安全性。”，达到 8 个字符是“设置口令会生成加密包，输对口令才能恢复。”系统保存框的默认文件名与过滤器随口令切换（`Diary2Day-Backup-<ts>.zip` / `.ddbak`）；Android 的“另存为”同理，MIME 分别为 `application/zip` 与 `application/octet-stream`。口令下方有“记住口令”复选框：勾选并在备份或恢复成功后，口令加密写进本机数据目录的 `backup-password.bin`，下次打开创建态或恢复态都会预填并勾选；不勾选完成操作则删除该记录。

**Android**：数据目录行（路径与两个图标）隐藏；导出/导入选目录，备份先弹 BackupDialog、再由“另存为”定备份包位置，恢复先选文件再确认；取消即原样返回；成功行显示文件名，不显示绝对路径。

- 同一时刻只跑一个操作：进行中所有动作行全部禁用，下面追加一行"操作名 + done/total"，进度来自 `dd://op-progress`。
- 失败在下面追加一行 `--c-danger` 的错误文案；成功追加一行 `--c-primary` 的结果（条数 / 路径 / 文件大小）。不弹系统 alert。
- 恢复、清空回收站、彻底删除与清理未使用附件共用确认框：选完备份文件先确认再替换整库；若确认后发现是加密包，再弹同一个对话框的恢复态（单个口令框，标题“输入备份口令”，同样带“记住口令”并预填已记住的口令），口令错误只在该框内报错并可重试，取消则不动数据；解密成功后才进入替换管线。成功后重载设置、锁态、容量与回收站。

**应用锁组**一行启用/关闭，启用后多一行"离开多久上锁"：0 / 30 / 60 / 300 / 600 秒，0 表示从不上锁（默认）。

- 口令输入用自绘的 CodeDialog，绝不使用系统 prompt：设置时两个输入（口令 + 确认），关闭时一个；规则 ≥4 字符、首尾不能有空格、两次输入一致；错误就地显示在框内，`Esc` 与取消都能退出。
- 锁屏 LockOverlay 盖满视口（`z-index` 高于一切浮层），底色 `--c-surface`，中央 360px 面板：56px 圆形锁徽标（`--c-primary-soft` 底）、标题、说明、居中密码框（`inputmode=numeric`，字距 0.2em）、整宽主按钮。错误描边与文案用 `--c-danger`，进出 180ms 淡入。
- 遮罩期间设置、主题与锁状态仍可读，保证主题能正常渲染；启动即锁定时路由视图不挂载，第一次解锁后才挂载并取数（运行时加锁仍保留已挂载视图，只盖遮罩）。其余数据请求由 Rust 侧拒绝，正文一个字节都不会到前端。

## 5. 交互态与动效

- **hover**：底色换 `--c-surface-2`，或叠 2% 黑遮罩，仅此两项。触屏端走 `@media (hover: hover)`，窄屏无 hover 态。
- **pressed**：浮动按钮缩放到 98%，其余元素靠底色加深。
- **focus**：`:focus-visible` 一律 `outline: 2px solid var(--c-primary); outline-offset: 2px`。鼠标点击走 `:focus-visible` 的默认行为，无环。
- **禁用**：38% 透明度 + `cursor: default`，字色保持原样；悬浮不出现底色或颜色变化。
- 动效三档时长：`--m-1 120ms`（淡入淡出、状态切换）、`--m-2 180ms`（吸附、折叠、左栏宽度）、`--m-3 240ms`（浮层进出）。缓动一条：`--ease: cubic-bezier(.2,0,0,1)`。位移量取 `--s-4` 或 `--s-6`。三档之外只留给周条吸附与浮层进出这类有信息量的动作。
- 动效由应用设置「关闭动画」控制，不跟随系统：开启后 `html[data-motion="reduced"]` 下三档时长归 0，打点呼吸动画停在静态态。

### 5.1 换日与换月动效

时间导航只有一条语义：**过去在左、未来在右**。去更早的日期，新内容自左入、旧内容向右出；去更晚的日期反向。离场层与进场层叠在同一格（月历与当日列表让离场层绝对定位，周条用网格叠放），离场层 `pointer-events: none`，不挡点击；容器尺寸由进场层决定，避免高度与宽度跳动。

| 动作 | 时长 | 位移 | 备注 |
|---|---|---|---|
| 周条换周 | `--m-2` 180ms | `--s-4` 16px | 横滑跟手，松手过半吸附；内容切换同向淡入淡出 |
| 月历翻月 | `--m-3` 240ms | `--s-4` 16px | 7×6 网格叠放，高度恒定；箭头与横滑都触发 |
| 当日列表换日 | `--m-3` 240ms | `--s-8` 48px | 旧列表整层退场，新列表进场；方向按日期先后 |
| 卡片出现 | `--m-1` 120ms | `--s-2` 8px 向上 | 只做进场，删除不做退场 |
| 路由切换 | `--m-1` 120ms | 无 | `out-in` 交叉淡入淡出（App.vue） |
| 宽屏选中条目 | `--m-2` 180ms | `--s-2` 8px | 旧条目淡出后新条目自右入；`?e=` 变化触发，详情栏内部 |
| 底部导航指示条 | `--m-2` 180ms | 一栏宽度 | `translateX`，跟手切页 |
| 主操作 / 浮动按钮按下 | `--m-1` 120ms | `scale(.98)` | 其余元素靠底色加深（§5） |

- 连续点日期以最后一次为准；过期请求丢弃（列表按 token 作废旧响应）。
- 列表容器保持 `scrollbar-gutter: stable`，换日时滚动条不闪。
- 应用设置"关闭动画"开启后，以上时长与位移全部归零，内容瞬时替换（`html[data-motion="reduced"]`）。

## 6. 主题、语言与 RTL

- 主题由 `session` 里一个设置驱动：设置只存具体主题 id，`applyTheme` 把 id 写进 `html[data-theme]`，同时把明暗写进 `html[data-scheme]`。组件只消费 token，Vditor 与原生控件的明暗判断读 `data-scheme`，不再逐个比较主题名。
- 首次启动时库里仍是 `system` 哨兵值，前端按 `matchMedia('(prefers-color-scheme)')` 选纸白/墨夜并写回具体 id，之后不再响应系统变化；切换任何主题只改这两个属性，不重载页面。
- 原生控件的明暗只认 `html[data-scheme]` 上的 `color-scheme`：时间输入的时钟图标、下拉弹层、滚动条都继承它。任何组件都不在元素上再写 `color-scheme: light dark`，否则会在系统与主题明暗不一致时露出白底或白色图标。
- 需要反色的图片走 CSS filter。
- 文案长度上限：英文按钮 ≤ 3 词、中文 ≤ 6 字；更长的动作改用图标 + tooltip。i18n 的实现见 DESIGN §5。
- RTL：`dir="rtl"` 一次翻转 + 全部 logical properties（DESIGN §5）。镜像清单 —— ←/→ 图标、周条与月历的排列方向、`text-align` 起点。保持原样 —— 表情图标、数字、日期、`ddasset://` URL、代码块。月历在 RTL 下的周起始与补白位置在 V-2 那轮一起验。

## 7. 自查与机器检查

每完成一屏做四件事（10 分钟内）：浅色/深色各截一张图并排看；4 种断点各看一次；切纯英文与纯中文各看一次；灌 1000 条真数据滚一遍首页。

`check-style.mjs`（DESIGN §8）在 CI 里拦三类写法：

1. 组件里出现十六进制色值 —— 色值只来自 §1.1 的 token。
2. `font-size` 落在 §1.2 的五档之外。
3. `!important` 出现在 `vditor-override.css` 之外 —— Vditor 的覆盖只集中在 §4 那一个文件。

一条判断题：某一屏同时出现三种以上分区手段（阴影、描边、底色、间距、标题）时，留一种，其余换成留白。
