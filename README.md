# Diary2Day

> 一款以「今天」为中心的本地日记应用。
> 打开就能写，内容与附件只存在本机；想带走时，一条不落地导出成普通 Markdown。

**打开就写** · **数据在自己手里** · **不联网也能用**

## 一分钟上手

1. **打开就写** —— 默认停在「今天」，在顶部卡片写下几笔；点发送或离开输入框即自动保存，空白内容不会生成记录。
2. **回看某天** —— 用周条或日历切换日期。只有今天可以编辑，历史和未来日期只读。
3. **想找回来** —— 在「发现」里搜正文，或按标签、心情筛选。
4. **带走全部** —— 在「我的」里导出 Markdown、生成备份，或恢复另一台设备上的数据。

## 功能一览

### 记录

- **今天卡片**：打开即写、自动保存，不产生空日记。
- **Markdown 正文**：标题、列表、任务、表格、代码块与图片。
- **本地附件**：图片、音频、视频随日记保存；底部按钮添加，桌面端还支持粘贴或拖入，图片点击可缩放、平移查看。

### 回看与查找

- **日历回看**：周条与整月视图，有记录的日期带圆点标记。
- **读写一体**：详情就是编辑器；历史日期保持只读。
- **快速找到**：全文搜索、标签与心情筛选。

### 导出与迁移

| 方式 | 得到什么 | 适合 |
|---|---|---|
| 导出 PNG | 按当前主题排版的分享长图 | 直接发给朋友 |
| 导出 Markdown 目录 | 每条日记一个 `.md`，附件在 `assets/` | 长期保存、用别的软件打开 |
| 备份 / 恢复 | 整库与附件，可设口令加密 | 换机、整库还原 |

- **PNG 长图**：在预览态点顶栏的图片按钮，把整篇日记按当前主题导出；宽度可在设置里连续调（320–1280px，默认 640px）；超长内容自动切成多张带序号的图片；正文里的大图按分享尺寸缩小，长图保持完整，原图不受影响。音频显示为进度条与总时长，视频显示封面帧与总时长，嵌入内容显示为一行说明；导出前选一次保存目录即可。
- **备份**：留空生成普通备份，或设置口令生成加密备份，只有输对口令才能恢复；可勾选「记住口令」，口令加密后只存在本机，不写入备份包，也无法找回。Android 上通过系统选择器完成同样的事，并可接收系统分享。
- **重新导入**：导出的 Markdown 目录可以再导回来。

### 外观

- **八套主题**：纸白、暖阳、海盐、樱粉、墨夜、夜蓝、可可、松林。主题页的卡片就是该主题的样子，连预览文字都各自贴合，点卡片即切换；首次打开按系统明暗默认使用纸白或墨夜。
- **自定义主题**：在预设之外另存多套自己的配色。四组底色（页面、卡片、凹陷、遮罩）可调颜色与不透明度，描边也可半透明；主文字、次要文字、强调色各自选色；再配背景图与界面字体——最多三个，可分别管英文与中文字形，按顺序回退；卡片上的标题与说明也能自己写。可存多张，同一时间生效一张；点已选中的卡片或长按任意自定义卡片即可编辑；删除主题时一并清理不再被引用的图片与字体文件。
- **个性化**：中英文、日期格式、卡片时间、首行缩进、打开即进入编辑、修仙模式（设定分界点，之前的记录算前一天）、导出图片宽度与关闭动画。

### 数据与隐私

- **数据一览**：设置页顶部显示数据库、附件、日记数、回收站与字数；数据目录一行可打开文件夹或复制路径。
- **附件清理**：手动「清理未使用附件」，扫描并删除没有正文引用的附件。
- **隐私**：可设置应用锁；数据只存本机，不依赖网络。

## 技术栈

Tauri v2 + Rust/SQLite；前端 Vue 3 + TypeScript + Vite，编辑器使用 Vditor。
