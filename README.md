# Diary2Day

Diary2Day 是一款以“今天”为中心的本地日记应用。打开就能写，内容与附件都保存在本机；需要时可以把全部日记导出成普通 Markdown 文件。

## 使用方式

1. 打开应用默认进入“今天”，在顶部卡片输入内容；点发送或离开输入框即自动保存，空白内容不会生成记录。
2. 用周条或日历切换日期。只有今天可以编辑，历史和未来日期用于回看。
3. 通过底部图片按钮添加图片、音频和视频；桌面端还支持粘贴或拖入文件。图片在详情中点击可放大查看。
4. 想分享某一条时，在预览态点顶栏的图片按钮，把这篇日记按当前主题导出成 PNG 长图；音频显示为进度条与总时长，视频显示封面帧与总时长，嵌入内容显示为一行说明。内容很长时会自动切成多张带序号的长图，导出前选一次保存目录即可。
5. 在“发现”中搜索正文，或按标签、心情筛选。
6. 在“我的”中查看数据概览与数据目录，导出、导入、备份和恢复数据；需要时点“清理未使用附件”扫描并删除没有正文引用的附件。备份时可留空生成普通备份，或设置口令生成加密备份；口令可记住，下次备份或恢复自动填入。还可调整主题、语言、日期格式、卡片时间、首行缩进、打开即进入编辑、修仙模式、导出图片宽度和关闭动画，并设置应用锁。
7. 在“主题”页点任意一张主题卡片即切换；首次打开时按系统明暗默认使用纸白或墨夜。

## 功能特色

- 今天卡片：打开即写，自动保存，不产生空日记。
- 读写一体：详情就是编辑器；历史日期保持只读。
- 日历回看：周条与整月视图，有记录的日期带圆点标记。
- Markdown 正文：标题、列表、任务、表格、代码块与图片。
- 本地附件：图片、音频、视频随日记保存；图片支持缩放和平移查看。
- 导出成图：预览态一键把整篇日记按当前主题导出为 PNG 长图，适合直接分享；导出宽度可在设置里连续调（320–1280px，默认 640px）；超长内容自动切成多张编号图片，正文里的大图会按分享尺寸缩小、长图保持完整显示，原图不受影响。
- 快速找到：全文搜索、标签与心情筛选。
- 八套主题：纸白、暖阳、海盐、樱粉、墨夜、夜蓝、可可、松林。主题页的卡片本身就是该主题的样子，连预览文字都各自贴合，点卡片即切换。
- 个性化：中英文、日期格式、卡片时间、首行缩进、修仙模式（设定分界点，之前的记录算前一天）、导出图片宽度、关闭动画。
- 数据一览：设置页顶部显示数据库、附件、日记数、回收站和字数；数据目录一行可打开文件夹或复制路径。
- 隐私：可设置应用锁；数据只存本机，不依赖网络。
- 数据可带走：导出为 Markdown 目录，支持重新导入、整库备份与恢复；备份可设口令加密，只有输对口令才能恢复（口令无法找回）；可勾选“记住口令”，口令以加密形式只存在本机，不写入备份包。Android 上通过系统选择器完成同样的事，并可接收系统分享。

## 技术栈

Tauri v2 + Rust/SQLite；前端 Vue 3 + TypeScript + Vite，编辑器使用 Vditor。
